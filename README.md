# ТехноСтар

IT-аутсорсинг и HR-решения. Адаптивный статический сайт на HTML, CSS и JavaScript.

Публикация в GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.

`index.html` находится в корне репозитория. Сборка и установка зависимостей не требуются. Файл `.nojekyll` отключает обработку Jekyll.

Лицензия шрифта Manrope сохранена в `assets/fonts/OFL.txt`. Источники оригинальных изображений и логотипов перечислены в `assets/assets-sources.json`.
